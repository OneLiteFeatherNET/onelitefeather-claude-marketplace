# Documentation

This plugin watches for redstone clocks, reports them to staff and can remove them. These pages
cover installing it, the jobs people actually do with it, every configuration value, and the
reasoning behind the parts that surprise people.

**New here?** [Your first detection](tutorial/first-detection.md) ends with the server reporting a redstone clock you built yourself.

**Trying to get something done?** The how-to guides cover the common jobs: [sending alerts to Discord](how-to/send-alerts-to-discord.md), [notifying staff in game](how-to/notify-staff-in-game.md), [excluding a world from detection](how-to/ignore-a-world.md) and [producing a debug log for a bug report](how-to/produce-a-debug-log.md).

**Looking up a value?** [Configuration](reference/configuration.md), [commands](reference/commands.md), [permissions](reference/permissions.md) and [supported versions](reference/supported-versions.md).

**Wondering how it works, or why?** [Detection modes](explanation/detection-modes.md) explains the trade-off behind the two modes. [Not a performance plugin](explanation/not-a-performance-plugin.md) and [unsupported platforms](explanation/unsupported-platforms.md) say what this plugin deliberately does not do, which is worth reading before opening an issue.
